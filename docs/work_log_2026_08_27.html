Objective: Stabilize the PostgreSQL deployment and advance the Web Investigation Framework from a containerized application into a FastAPI-based, queued microservice architecture with a single Streamlit user interface.

Work Completed

  13. Added PostgreSQL-backed job records with queued, running, completed and failed states.
  14. Added job acknowledgement, unacknowledged-job recovery and a worker heartbeat health check.
  15. Added FastAPI endpoints for submitting OSINT and Dynamic jobs and reading job status.
  16. Connected the Streamlit UI to FastAPI so investigation buttons now submit queued jobs rather than running orchestrators inside Streamlit.
